# Fig. 6 source data

- `SourceData_Fig6A_projection_profiles.csv`: terminal and selected internal-
  branch profile coordinates used by panel A.
- `SourceData_Fig6BC_species_fingerprints_long.csv`: all 71 marine and 101
  aquatic-dependence contributions for the six terminal portraits.
- `SourceData_Fig6_fullData_species_projections_all_focal.csv`: full-data fitted
  projections for all focal terminal species considered during figure design.
- `selected_internal_node_projections.csv`: terminal-only model projections of
  selected internal branches used as descriptive coordinates.
- `selected_internal_node_target_audit.csv`: branch identity/provenance audit.

Terminal and internal rows are descriptive fitted projections after model
validation. They are not out-of-fold probabilities or ancestral habitat calls.
