# Source data

This directory contains lightweight source tables used to verify manuscript
figures, supplementary figures and supplementary tables. Full branch-coordinate
matrices, GBI matrices and other large analysis products are stored in Dryad
under DOI https://doi.org/10.5061/dryad.dz08kpsd4.

See `../data_manifest/source_data_manifest.tsv` for file sizes, SHA256 checksums
and brief descriptions of the source-data files included here.

The current NC additions are the Fig. 6 and Fig. S3 directories. Their
scientific values are copied from reviewed NC analysis outputs; the submission-
checklist work added only packaging, documentation and validation checks.
