# Release plan

## GitHub

Recommended contents: code, lightweight source data, manifests, expected-count
smoke tests, documentation, and checksums.

Current release tag: `v1.1-analysis-update`. The immutable
`v1.0-endpoint-fix` tag remains available as the endpoint-fix baseline. The
analysis update adds current Fig. 6/Fig. S3 code, lightweight Source Data and
reviewer-facing reproducibility checks.

## Data archive

Recommended contents: full branch-coordinate matrices, endpoint-fix GBI matrix,
processed screening tables, and any large permutation/null outputs not committed
to GitHub. Dryad DOI is reserved as
https://doi.org/10.5061/dryad.dz08kpsd4; Dryad public release is pending
manuscript publication. During peer review, reviewers should use the private
Dryad link provided in the manuscript.

## External source data

TOGA-derived Hiller Lab coding-gene alignments should be cited and linked. Do not
rehost the raw external alignment bundle unless upstream redistribution permission
is confirmed.
