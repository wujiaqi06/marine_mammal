# Data directory

This GitHub repository does not store large analysis matrices. Large
study-generated inputs and outputs are deposited in Dryad under DOI
https://doi.org/10.5061/dryad.dz08kpsd4.

See `../docs/dryad_manifest.md` and `../data_manifest/` for the large-data
boundary and checksum/source manifests. Lightweight figure and supplementary
table source data are stored in `../source_data/`.
